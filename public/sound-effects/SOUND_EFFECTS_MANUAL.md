# Motion-video sound-effects manual

The library contains 148 audio files organized into nine searchable folders. Filenames use lowercase `category_action_character_timing_variant` terms so an AI can match a visual cue to a sound.

## Selection rules

- `Camera Shutters`: photo capture, freeze-frame, camera-cut transitions.
- `Clicks`: buttons, taps, selections, confirmations, cursor actions, and short UI responses.
- `Data Collect`: data streams, counters, score tallies, stopwatch/countdown information.
- `Gear`: mechanical, industrial, clockwork, and rotating-machine motion.
- `Money`: cash, coin, financial, or money-reveal moments.
- `Pop`: object appearance, reward, bounce, material change, and popup accents.
- `Risers`: suspense builds, countdown starts, title impacts, and dramatic reveals.
- `UI Sound Effects`: typing, menus, alerts, glitches, open/close states, and general interface sounds.
- `Whooshes`: movement, swipes, camera pans, text slides, and fast transitions.

## Duplicate cleanup

Exact byte-identical duplicates were removed. The retained library contains no remaining exact duplicate audio hashes.

Removed duplicates included the duplicate confirm, dismiss, and clean-click exports from the original root set, plus the duplicate `Clicks/Click_2.wav` that matched the original camera-shutter sound. The remaining similarly named variants are not byte-identical and were retained as separate choices.

## Naming convention

Use lowercase snake case. Prefer searchable terms in this order:

`category_action_character_timing_variant.ext`

Examples: `ui_button_glassy_click_short_03.wav`, `whoosh_cinematic_long.wav`, and `transition_reverb_heavy_reveal.mp3`.
